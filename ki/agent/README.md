# Assistenten

Ein Assistent ist ein KI-Helfer mit eigenem Raum: ein Projekt in Claude oder ChatGPT, ein GPT oder ein Agent in Le Chat. Ihr richtet ihn einmal ein, und dort ist jede Nachricht ein neuer Auftrag. Ein [Skill](../skills/README.md) dagegen startet in einem normalen Chat von selbst, sobald eure Frage passt.
