# Pakete zum Hochladen

Hier liegt jeder Skill als ZIP-Datei, also als gepackter Ordner. In dieser Form nehmen Claude und Gemini Skills an. In jedem Paket liegt nur die `SKILL.md` aus dem Ordner des Skills. Ihr könnt sie vorher dort lesen.

| Paket | Skill |
|---|---|
| [faktencheck.zip](faktencheck.zip) | [Faktencheck](../faktencheck/README.md) |
| [herkunftscheck.zip](herkunftscheck.zip) | [Herkunftscheck](../herkunftscheck/README.md) |
| [themenrecherche.zip](themenrecherche.zip) | [Themenrecherche](../themenrecherche/README.md) |
| [expertenmeinungen.zip](expertenmeinungen.zip) | [Expertenmeinungen](../expertenmeinungen/README.md) |
| [pdb-helfer.zip](pdb-helfer.zip) | [PDB-Helfer](../pdb-helfer/README.md) |
| [prompthelfer.zip](prompthelfer.zip) | [Prompthelfer](../prompthelfer/README.md) |

## So geht's

1. Paket anklicken, dann oben rechts auf den Pfeil nach unten („Download raw file“).
2. **Claude:** nicht entpacken, die ZIP-Datei so hochladen. **Gemini:** erst entpacken, dann den Ordner hochladen.

Schritt für Schritt steht es in der [Anleitung](../README.md#so-gehts).
