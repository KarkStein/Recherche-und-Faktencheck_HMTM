# Gesamtpaket: alles ohne GitHub

Hier liegt der ganze Werkzeugkasten als eine ZIP-Datei: zum Weitergeben, zum Lesen ohne Internet und für alle, die mit GitHub nichts anfangen wollen.

**[Werkzeugkasten_Recherche_Faktencheck.zip](Werkzeugkasten_Recherche_Faktencheck.zip)** · anklicken, dann oben rechts auf den Pfeil nach unten („Download raw file“)

## So geht's

1. Herunterladen und entpacken: unter Windows Rechtsklick und „Alle extrahieren“, am Mac Doppelklick.
2. `Werkzeugkasten.html` doppelklicken. Die Datei öffnet sich im Browser, auch ohne Internet.

## Was drin ist

| Datei oder Ordner | Was drin ist |
|---|---|
| `Werkzeugkasten.html` | alle Seiten in einer Datei, mit Inhaltsverzeichnis und Knöpfen zum Kopieren der Skills und Prompts |
| `Skills_zum_Kopieren/` | jeder Skill und Moby als Textdatei, Lang- und Kurzfassung |
| `Skills_zum_Hochladen/` | die Pakete für Claude und Gemini |
| `Fuer_KI-Chats/` | alle Seiten als eine Textdatei, ohne die Skill-Texte: in einen KI-Chat hochladen, dann beantwortet er Fragen zum Werkzeugkasten |
| `Folien_Recherche_und_Faktencheck.pdf` | die Seminarfolien, ohne Sprechernotizen |
| `Spickzettel.pdf` | der Spickzettel zu KI-Tools |
| `LIESMICH.txt` | diese Anleitung in Kurzform |

Das Paket wird aus den Dateien in diesem Repo gebaut. Es ist so aktuell wie das Stand-Datum in der HTML-Datei. Die neueste Fassung liegt immer hier.
